# 🛒 SuperKart Sales Prediction & Business Intelligence Dashboard

An AI-powered retail sales prediction project developed during the NTI AI for Business Training Program.

## 📌 Project Overview

This project predicts product sales using Machine Learning and provides an interactive dashboard for business insights.

## 🚀 Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- XGBoost Regression Model
- Sales Prediction
- Interactive Streamlit Dashboard

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Streamlit
- Plotly
- Git & GitHub

## 📊 Dataset

SuperKart Retail Sales Dataset
